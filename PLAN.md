### 4.1 Submission (Applications)
- user_id (owner)
- track_name (required)
- artists_display (required)
- cover_option (LINK | LABEL_DESIGN) (required)
- cover_link (required if cover_option=LINK)
- audio_link (required)
- spotify_link (required)
- tiktok_link (optional)
- artist_email (required)
- artist_legal_name (required)
- artist_country (required)
- artist_city (required)
- artists_count (required: 1/2/3/4/5+)
- participants (2-4 artists only): role/fullname/country/city/email/spotify
- bulk_artist_list (required if 5+)
- status: NEW / OK / NEEDS_FIX / DESIGN_REQUESTED / REJECTED
- admin_note (optional)
- public_token (secret token for status page)

### 4.2 User
- email, display_name
- password_salt, password_hash
- is_admin

### 4.3 Draft
- token
- data (json)

### 4.4 Release
- submission_id
- status: IN_PREP / APPROVED / SCHEDULED / REJECTED
- release_note (optional)

### 4.5 PlannedCatalog
- release_id
- created_at

## 5) UX Rules
- Cover option:
  - LINK => cover_link required
  - LABEL_DESIGN => cover not required
- Audio:
  - link only
- Artists:
  - If 1 => no participants block
  - If 2-4 => repeatable participant section (4 fixed blocks, use first N)
  - If 5+ => show bulk field and require it
- Status visibility:
  - Artist sees only their submissions (by owner + token)
  - Admin sees everything
